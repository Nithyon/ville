VILLE

Verified Inference Leak Locator using E-values

Team REIGN · Chittimilla Saitarun · SaiNithin Pokala

A hacked AI inference server can leak its model weights by hiding bits in normal-looking word choices. VILLE replays each prompt on a trusted machine, looks at where the words differ, and adds up the evidence over many responses. It raises an alert while it keeps the chance of any false alarm below 1 percent. The detector comes from recent research. Team REIGN adds a drop-in monitor, automatic recalibration, an automatic response that blocks the data an attacker needs, and one security dashboard.
